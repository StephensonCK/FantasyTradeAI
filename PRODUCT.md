# Fantasy Trade AI

A React web tool for fantasy football managers comparing redraft trades. Users select scoring, quarterback format and league size, add players to either side, read a market-value verdict, and optionally add suggested players to balance the trade. FantasyCalc supplies values; depth discounts are heuristic. Preserve these functions, saved settings, and light/dark themes. Courtney requests a bold football and technology redesign with WCAG 2.2 accessibility; target AA. No invented performance or AI claims.
